# Hi Five by Jia — hifivebyjia.in

The online shop for **Hi Five by Jia**, a handmade accessories brand started by Jia (Nainu at home).
Built with **Next.js 16 (App Router) · TypeScript · Tailwind CSS v4**, deployed on **Vercel**.

> Made with Creativity. Shared with a Smile. ✋

---

## Quick start

```bash
npm install
cp .env.example .env.local   # then fill in values (all optional for local dev)
npm run dev                  # http://localhost:3000
npm run lint
npm run build && npm start   # production build
```

Node 20.9+ is required (Node 22 recommended).

## Admin dashboard — manage the shop without code

Everything is managed at **`/admin`** (password protected): products & photos, prices, stock,
coupons & offers (percentage / fixed / buy-X-get-Y, max discount, minimum order, start & end dates,
usage limits), orders, review approval, Notify-me lists, contact messages, collections, a category master,
shipping and the WhatsApp number. Changes appear on the website immediately.

- **Owner’s guide:** [`docs/ADMIN-GUIDE.md`](docs/ADMIN-GUIDE.md)
- **One-time setup:** connect a free Postgres database and set `ADMIN_PASSWORD` — see [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)

Without a database the website still works from the files in `src/data`, and `/admin` shows setup steps.

## Editing content

Day-to-day changes (products, prices, stock, photos, coupons, collections, shipping, WhatsApp) are made in
**`/admin`**. The files below hold the starting data copied into the database on first run, plus the text
that rarely changes:

| What | Where |
| --- | --- |
| Brand name, URLs, email, tax, feature flags | `src/config/site.ts` |
| Navigation & footer links | `src/config/navigation.ts` |
| Brand story, Meet Nainu, microcopy | `src/content/brand.ts` |
| FAQ, shipping, returns, privacy, terms text | `src/content/help.ts` |
| Starting products / collections / coupons (first run only) | `src/data/*.ts` |
| Design colours & fonts | `src/app/globals.css` (`@theme` tokens) |

### Official logo

The logo lives at `public/brand/logo.jpg` and is configured in `siteConfig.logo` (`src/config/site.ts`).
It is always rendered exactly as supplied — only scaled, never recoloured, cropped, redrawn or given effects.
Favicons (`src/app/icon.png`, `src/app/apple-icon.png`) are straight resizes of the same file.
To update it, replace the file (keep the name or update `logo.src`, `width`, `height`) and re-create the favicons:
`convert public/brand/logo.jpg -resize 192x192 src/app/icon.png` (and `-resize 180x180 src/app/apple-icon.png`).

The site palette in `globals.css` is sampled from the logo: pink `#ED0C68`, teal `#01BDC6`, yellow `#FAAF04`, purple `#7721C2`.

### Product images

Upload real photos in **Admin → Products** (they’re resized in the browser and stored in the database).
The starting products use labelled illustrations from `public/products/<slug>/`
(generated by `scripts/generate-product-art.mjs`) — replace them with photos in admin.

### Sample products

Products marked **Sample listing** (Pearl Charm Bracelet, Pastel Stack Set, Best Friends Duo, Rainbow Anklet)
show how adult/gift products look. Delete them or set them to *Hidden* in admin.

## Orders, reviews and messages

Checkout orders, reviews, Notify-me sign-ups and contact messages are POSTed to `/api/forms/[type]`, which
validates, sanitises and rate-limits them, then saves them to the database (shown in admin). Orders are
**re-priced on the server** (products, coupon and shipping from the database), so the admin always shows the
correct total. Reviews are stored as *pending* and only appear after approval.

Optionally set `FORMS_WEBHOOK_URL` to also forward every submission as JSON (e.g. to a Google Sheet).

## Child privacy

Jia is a minor. The site intentionally publishes **no** address, phone number, personal email, school name,
location or routine. Only "Jia is currently studying in Grade 5" is shown (toggle in `src/content/brand.ts`).
The Nainu mascot is a stylised illustration, not a portrait. Keep it that way when editing content.

## Analytics

Set any of these in Vercel to enable — nothing loads without them:
`NEXT_PUBLIC_GA_MEASUREMENT_ID`, `NEXT_PUBLIC_META_PIXEL_ID`, `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`.
Events (view_item, add_to_cart, begin_checkout, whatsapp_order, search, …) are sent via `src/lib/analytics.ts`.

## Project structure

```
src/
  app/(shop)/     storefront pages
  app/admin/      admin dashboard (login + panel)
  app/api/        forms, coupons, images, admin uploads/exports
  server/         database, schema/seed, store loader, auth, server actions
  components/     UI: brand, layout, home, product, shop, cart, checkout, reviews, forms, common
  config/         site config & navigation (single source of truth)
  content/        editable copy (brand story, FAQ, policies)
  data/           starting products, collections, discounts (seeded into the database)
  lib/            catalog queries, pricing engine, validation, SEO, WhatsApp, analytics, repositories
  store/          localStorage-backed cart / wishlist / records (useSyncExternalStore)
  types/          domain types + future database models
docs/             architecture, database schema, deployment
scripts/          product illustration generator
```
