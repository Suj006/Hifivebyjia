# Hi 5 by Jia — hifivebyjia.in

The online shop for **Hi 5 by Jia**, a handmade accessories brand started by Jia (Nainu at home).
Built with **Next.js 16 (App Router) · TypeScript · Tailwind CSS v4**, deployed on **Vercel**.

> Made with Creativity. Shared with a Smile. ✋

---

## Quick start

```bash
npm install
cp .env.example .env.local   # then fill in values (all optional for local dev)
npm run dev                  # http://localhost:3000
npm run lint
npm run build && npm start   # production build
```

Node 20.9+ is required (Node 22 recommended).

### Adding the official logo

1. Save the logo file exactly as supplied to `public/brand/logo.png` (or `.svg`/`.webp`).
2. In `src/config/site.ts`, set:
   ```ts
   logo: { src: "/brand/logo.png", width: <real px width>, height: <real px height>, alt: "Hi 5 by Jia" },
   ```
The logo is rendered as-is (no recolouring, cropping or effects). Until then a plain text wordmark is shown.
Optionally re-tune the colour tokens in `globals.css` to match the logo palette.

### Product images

Current images in `public/products/<slug>/` are **labelled illustrations** generated by
`scripts/generate-product-art.mjs`. Replace them with real photos (JPG/PNG/WebP, square works best)
and update the `images` list for that product in `src/data/products.ts`. Photos are automatically
optimised (AVIF/WebP, lazy-loaded) and never cropped on product pages.

### Sample products

Products with `isSample: true` (Pearl Charm Bracelet, Pastel Stack Set, Best Friends Duo, Rainbow Anklet)
are demo listings showing how adult/gift products look. They display a "Sample" tag. Replace or delete them.

## Receiving form submissions (Phase 1)

Reviews, Notify Me, contact messages and order requests are POSTed to `/api/forms/[type]`, which validates,
sanitises, rate-limits and (if `FORMS_WEBHOOK_URL` is set) forwards them as JSON:

```json
{ "type": "review", "receivedAt": "2026-10-05T10:00:00.000Z", "data": { "productId": "p-keychain", "name": "Asha", "rating": 5, "text": "…", "status": "pending" } }
```

Any webhook receiver works — a Google Apps Script writing to a Google Sheet, Formspree, Make, Zapier, etc.
`FORMS_WEBHOOK_SECRET` (optional) is sent as the `X-Webhook-Secret` header.

**Publishing a review:** copy an approved submission into `src/data/reviews.ts` with `status: "approved"` and redeploy.
`/admin/reviews` is a no-index, device-local preview of the moderation actions (approve / reject / feature / delete)
that the Phase 2 admin dashboard will provide.

## Child privacy

Jia is a minor. The site intentionally publishes **no** address, phone number, personal email, school name,
location or routine. Only "Jia is currently studying in Grade 5" is shown (toggle in `src/content/brand.ts`).
The Nainu mascot is a stylised illustration, not a portrait. Keep it that way when editing content.

## Analytics

Set any of these in Vercel to enable — nothing loads without them:
`NEXT_PUBLIC_GA_MEASUREMENT_ID`, `NEXT_PUBLIC_META_PIXEL_ID`, `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`.
Events (view_item, add_to_cart, begin_checkout, whatsapp_order, search, …) are sent via `src/lib/analytics.ts`.
